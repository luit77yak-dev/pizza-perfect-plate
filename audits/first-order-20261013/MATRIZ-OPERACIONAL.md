# Matriz operacional — escopo real e limites

| Fluxo                                                       | Estado                              | Evidência / limite                                                                                                                              |
| ----------------------------------------------------------- | ----------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| Catálogo domínio A1, tamanho, borda, obrigatórios/opcionais | Comprovado                          | Chromium lê backend nativo; grande+5, recheada+2, obrigatório+2, opcional+3                                                                     |
| Sacola e quantidade                                         | Comprovado                          | Quantidade2, unidade42, subtotal84; valores comparados ao PostgreSQL                                                                            |
| Entrega/endereço/área válida                                | Comprovado                          | Nome/telefone/rua/número/bairro fictícios; taxa alterada4→7 requer nova revisão; total91                                                        |
| Checkout e persistência única                               | Comprovado                          | Confirmar abre tracking automaticamente; não apenas HTTP200; SQL compara instância, campos, itens e snapshot2                                   |
| Painel /admin/pedidos                                       | Comprovado, mínimo operacional      | Login Auth real, detalhe RPC autorizado, itens/quantidades/adicionais/endereço/valores e conclusão; não CRUD comercial completo                 |
| /painel legado                                              | Não homologado                      | Rota preservada, contrato legado usa org/nomes de tabelas diferentes; sem prova de isolamento A1/A2                                             |
| Transições e histórico                                      | Comprovado na proposta candidata    | RECEIVED→CONFIRMED→PREPARING→READY→OUT_FOR_DELIVERY→DELIVERED; salto rejeitado; repetição não duplica evento; política comercial requer revisão |
| Tracking privado                                            | Comprovado                          | Mesma prova/pedido da criação, sem telefone sozinho; reflete mudanças GUI, mantém terminal em memória                                           |
| Append privado                                              | Comprovado                          | RPC/capacidade e HTTP prévios, NOT_SETTLED, replay sem itens extras e token bloqueado em outra loja                                             |
| Timeout, perda de resposta, browser reaberto, duas abas     | Comprovado                          | H03/H04 completos reexecutados no runtime candidato; mesma chave e SQL com um pedido                                                            |
| Payload alterado/expirado                                   | Comprovado no backend e contratos   | Hash diverge: rejeita; lease expirada: bloqueia, sem chave nova                                                                                 |
| Storage indisponível                                        | Comprovado                          | Zero POST; não fallback para outro navegador                                                                                                    |
| localStorage removido, memória/cookie mantidos              | Comprovado                          | Marcador de negação bloqueia repetição, também depois de reload; sem nova gravação                                                              |
| Cookies+storage+memória/perfil completamente perdidos       | Bloqueado                           | Não há identidade anônima verificável; não declarar reconciliação segura nem deduplicação universal                                             |
| Reconciliação com chave conhecida                           | Comprovado                          | Auth por instância, actor auditado; lock/fence serializa com criação; não confirma pagamento nem emite append                                   |
| Reconciliação sem chave/prova                               | Bloqueado                           | UNKNOWN; telefone não comprova ausência, operador não deve liberar nova chave                                                                   |
| Restore GROUP populado                                      | Comprovado                          | 202 checks; intenção/hash/lease/snapshot/dinheiro, Auth/PGRST do destino, retry sem duplicar                                                    |
| DR entre clusters                                           | Não executado                       | Destino é outro banco no mesmo cluster; roles globais compartilhadas                                                                            |
| A1/A2/B1                                                    | Comprovado nos cenários             | Entregas reais por RPC, chaves iguais segregadas, taxas próprias, recuperação/cruzamento/append bloqueados e usuários reais no GUI              |
| Resposta administrativa atrasada e troca de contexto        | Comprovado                          | Segura resposta real A1, seleciona A2, libera; nada A1 reaparece                                                                                |
| Backend indisponível                                        | Comprovado para falha de transporte | HTTP503 injetado na resposta de lista; dados antigos removidos. Não é prova de indisponibilidade física prolongada                              |
| Auth e sessão encerrada/expirada                            | Comprovado no cenário               | GoTrue emite lease curto; válido antes, rejeitado pelo PGRST após janela observada; GUI remove sessão/dados                                     |
| 360/390/412/768/1440                                        | Comprovado no Chromium              | Cliente e painel, capturas por tela, sem overflow do documento; não celular físico/teclado virtual                                              |
| Teclado/foco                                                | Registrado nos checks finais        | Foco nome→telefone e e-mail→senha; não auditoria WCAG completa                                                                                  |
| Sandbox/produção/pagamento real                             | Não executado                       | Proibidos; nenhum deploy, merge, alteração remota ou settlement                                                                                 |
